# MABYE STAR · 也许之星

一个以紫发少女为主角的迷你**银河恶魔城**（Metroidvania）游戏。
浏览器即开即玩，零依赖（原生 Canvas + WebAudio）。

## 怎么玩

在仓库根目录起一个静态服务器，例如：

```bash
python3 -m http.server 8000 --bind 0.0.0.0
```

然后打开 `http://localhost:8000`（或本环境的实时预览）。

## 操作

| 按键 | 动作 |
| --- | --- |
| ← → / A D | 移动 |
| Z / 空格 / K | 跳跃（二段跳解锁后空中再按一次） |
| X / J | 攻击（可击碎裂纹砖） |
| C / Shift | 冲刺（带短暂无敌，可穿过尖刺带） |
| ↓ + 跳 | 下穿单向平台 |
| E / ↑ | 互动（长椅休息 = 存档点） |
| M / Tab | 星图（小地图） |
| P / Esc | 暂停 |
| N | 静音 |

## 内容

- 一张互联大地图：星之遗迹 → 西部洞窟 → 北方竖井 → 天台 → 蚀星者 Boss 战
- 能力门控探索：**冲刺 → 蹬墙跳 → 星步二段跳**，拿到新能力后旧区域有新路
- 7 枚星星碎片、3 个生命上限、可破坏砖藏宝、长椅存档（localStorage）
- 程序生成的芯片音乐与环境音（WebAudio 合成，无音频资源）

## 角色

`assets/hero.png` 是按角色设定图用 `tools/paint_hero.py` 逐像素绘制的 9 帧动画条
（idle / blink / run×4 / jump / dash / attack）：高挑纤细的成熟女性，7.5 头身，
长黑发、紫罗兰眼、黑色露肩针织裙、漆皮高跟过膝靴、颈环。
改姿势或配色后运行 `python3 tools/paint_hero.py assets/hero.png` 重新生成；
`tools/preview.py` 可渲染放大预览图。

## 美术（v4：歧路旅人 × 死亡细胞）

- HD-2D 手绘背景：黄昏大教堂遗迹、晶簇地下湖、月夜浮岛云海，
  烘焙泛光 / 轮廓光 / 体积神光，远景柔和虚化（`tools/paint_env.py`）
- 死亡细胞式地砖：噪波抖动纹理 + 深色剪影描边 + 边缘轮光，
  三生态（苔砖 / 晶岩 / 星纹大理石）自动贴砖（`assets/tiles.png`）
- 实时后期：bloom、神光扫过、暗角；分区氛围粒子
  （废墟花瓣尘光 / 洞窟孢光 / 天台飘雪 / Boss 余烬）
- 角色 14 帧动画：落地缓冲、蹬墙、受击、三段连击各自动作 + 头发裙摆随动；
  冲刺残影、二段跳星环、敌人死亡魂光、Boss 消散冲击环
- `tools/shot.py` 可离线合成实机贴砖截图用于美术自检

## 关卡设计（v4）

- 教-练-考节奏：冲刺圣所 → 安全练习坑 → 刺带 → 深沟门控
- 每个难度门控前设长椅与提示牌；危险全部可见（刺坑不藏雷）
- 竖井改为厚实阳台台缘（≤3 行台阶），告别单调天梯
- `tools/headless.js` 24 项断言含「无冲刺必落坑」「练习坑可徒手跳出」公平性检验

## 手感

- 可变跳高（松开跳键截断上升）、土狼时间、输入缓冲
- 冲刺 0.18s 无敌帧 + 结束后保留动量，跳跃 apex 衔接冲刺可跨 6 格深沟
- 三段连击（第三段重击震屏）、受击重 knockback + 落地扬尘
- 相机前瞻与垂直死区、落地压扁/起跳拉伸、心跳低血警告
